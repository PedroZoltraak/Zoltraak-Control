# Zoltraak Control Telemetry — Website v0.2

Site estático oficial do projeto, pronto para teste local e publicação via GitHub Pages.

## Testar no Windows
Abra `index.html` a partir da pasta extraída. Não abra de dentro do ZIP/RAR.

## Publicar no GitHub Pages
Copie o conteúdo desta pasta para a raiz do repositório (ou para a branch/pasta configurada no GitHub Pages) e habilite Pages em **Settings → Pages**.

## Principais melhorias da v0.2
- Hero mais forte com gameplay real e telemetria animada.
- Screenshots reais do Zoltraak Control.
- Galeria com visualização ampliada.
- Seção de gameplay real.
- Demonstração interativa de layouts Full / Compact / Minimal.
- Guia UDP mais visual.
- Seção Sobre e Download redesenhadas.
- FAQ, SEO, Open Graph e dados estruturados.
- Português/Inglês.
- Integração com GitHub Releases para versão, contador e link direto do instalador.
- Layout responsivo para desktop e mobile.
